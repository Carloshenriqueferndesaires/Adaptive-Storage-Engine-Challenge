## 1. Sobre o projeto

O Adaptive Storage Engine Challenge é um projeto desenvolvido para implementar um motor de armazenamento persistente em Python.

O sistema recebe operações de armazenamento por meio de um arquivo de workload, executa operações de inserção (PUT), consulta (GET) e exclusão (DELETE) e registra os resultados em um arquivo de saída.
